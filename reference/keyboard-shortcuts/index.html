Keyboard Shortcuts

Hotkey reference aligned with the in-app Keyboard Shortcuts legend, plus a few extra app-wide keys.

This page follows the Keyboard Shortcuts legend in the app (tree toolbar K, status bar Shortcuts). A short Also useful section at the end lists a few extra keys that are real in the product but not every row in that legend.
[!IMPORTANT] Open Joe: Cmd+Shift+A / Ctrl+Shift+A toggles the Joe chat panel (open / minimize to a floating pill / restore). Ctrl+J copies node JSON — it does not open Joe. New node: N / Ctrl+N (not Enter or Tab). On Mac, Cmd+N is New Flow, not add node.

​
Confirmation and text prompts

In ordinary confirmation and single-text-entry prompts, Tab and Shift+Tab move through the current controls and wrap within the prompt. Closing returns keyboard focus to the control you came from, unless you have already moved focus to another window. Screen readers can identify the prompt by its displayed title and hear the text field’s instructions. Custom choice prompts follow the same Tab and return-focus behavior; Escape also closes an Info notice.

Rich-text editor

These apply inside the rich-text editor — Node Summary, Flow Summary, slot Preview notes, and gallery slot/stack notes. They mirror the in-app Keyboard Shortcuts & Formatting Guide on the editor toolbar.
HotkeyAction
Cmd/Ctrl+BBold
Cmd/Ctrl+IItalic
Cmd/Ctrl+UUnderline
Cmd/Ctrl+Shift+SStrikethrough
Cmd/Ctrl+Shift+HHighlight
Cmd/Ctrl+KAdd / edit hyperlink
Cmd/Ctrl+Alt+1 / 2 / 3Heading levels
Tab / Shift+TabIndent / outdent a list item
Cmd/Ctrl+ZUndo (50-level, persistent)
Cmd/Ctrl+Shift+ZRedo

/Slash command menu (at a word boundary)
:Emoji menu (at a word boundary)

There are no text-alignment shortcuts — Cmd+Shift+R collided with the browser’s hard-reload, so that set was removed. Use the toolbar’s alignment dropdown.
