  1. Joe (AI Collaborator)

Transcribe audio

Turn a recording into text for free on your computer, or use your paid OpenAI API account.

Turn interviews, voice notes and other recordings into editable text by asking Joe in Chat or using the Transcribe tab. You can use free transcription on your computer or the paid online service. The local transcription engine does not need an API key; chatting with Joe uses your selected brain as usual.

​
Ask Joe to transcribe

Keep the audio file in a gallery slot or stack, then ask “Can you transcribe this recording?” You can also name a recording in another accessible node. Joe uses your saved method, model, language and local output format. Your request starts the run without another approval. Joe starts a background job and becomes available for your next message. A compact card above the message box shows progress and elapsed time. A moving highlight means the job is active but has no measured percentage yet; a solid fill shows measured progress. With reduced motion enabled, the activity highlight stays still. Use Stop transcription on that card to cancel only the recording job; Chat’s usual Stop controls the current reply. Closing Joe’s panel does not stop transcription, but FlowJoe must stay open. Jobs do not resume after app restart. If the recording is unclear, choose the recording Joe offers. If local transcription needs setup, open the setup link, select or install a model in Transcribe, then ask again. Joe never switches from local to paid online transcription automatically. You can ask “How is the transcription going?” while discussing something else. Local jobs show approximate time remaining after enough recognition progress is available; until then, or when the engine provides no reliable progress, the card says Estimating time remaining…. Joe does not spend model calls polling. Completion arrives as an event; a chat notice waits until any active reply finishes and belongs only to the conversation that started the job. The full result is kept in Recent transcripts. Completion still shows the opening lines of the transcript, plus Open and Copy. Use Open beneath the result to edit that exact transcript in Transcribe, or Copy to copy the text. Joe can discuss the result afterward. A gallery copy is a separate save. Starting transcription from Chat requires the owner’s Propose & modify Flow access. Guest transcription remains available through the existing Transcribe tab.

​
API, CLI and MCP

The shared action transcribe_audio accepts the source nodeId and recording’s stable entryId from the Flow snapshot. A stack recording uses its own entry ID. Joe’s API brains, supported CLI brains and authenticated external Agent Bridge clients can use it with Propose access. External API/CLI/MCP calls keep their existing waiting behavior and retain results without opening or changing Chat. Native API Chat and native CLI brains start detached jobs by default. The same tool accepts action: "status" with the returned jobId (omit it for the latest job), or action: "cancel" with an exact job ID. Status includes state, measured progress and nullable remainingMs; only completed results report saved and a record ID. Background controls are native Chat only; an external session cannot inspect or cancel native Chat jobs. It is not offered to scheduled runs. For the standalone CLI, put the IDs in input.json: 
{"nodeId":"YOUR_NODE_ID","entryId":"YOUR_AUDIO_ENTRY_ID"}

flowjoe-cli action transcribe_audio --file input.json --wait 3600 --json
Agent Bridge must be enabled and FlowJoe must remain open. Choose a wait long enough for your recording and computer; Ctrl+C cancels. Multiple external matches return choose_audio and IDs to resolve with the user. The result includes recordId, saved, text and truncated. The returned text is limited to 12,000 characters; the retained transcript is complete. For more, use query_history with kind: "transcript", then read_history with the returned revision and continuation. See the CLI action reference.

For a recording in a Private node, unlock the node before starting. Choosing online transcription sends the recording to your chosen provider in the usual way; Private status does not add another consent step. Your method, local model and local output format are remembered on this computer. Switching methods keeps your paid model choice. FlowJoe does not switch to a paid service if a local run fails.

Set up free local transcription

  1. Open Joe and choose Transcribe. Keep your audio recording in a gallery slot or stack in the selected node.
  2. Choose Set up Whisper, or Manage local models if models are already available.
  3. FlowJoe checks for compatible models already on your computer. Ready on this computer means the Whisper model is installed. Setup also shows whether speaker labels are installed. Choose a model, read its size and description, then click Use once the required downloads are ready.
  4. If you need a model, choose one under Download once and click its Download button. A model is the file that recognizes speech. FlowJoe downloads and checks the model and the speaker-label tools together. If Whisper is already installed, choose Download speaker labels to get only the missing tools. The download size is shown before setup; you do not need a terminal or a separate software installer.
  5. Wait for the model to become ready, then click Use. Downloading alone does not change your transcription method or saved model.
You can cancel a download and try again. If the Whisper model finishes but the speaker download fails, retry keeps the completed model and downloads only the missing tools. Back returns to Transcribe without changing your saved method/model. Your selected recording and existing transcript stay in place.

​
Which model should I choose?

Small is a balanced starting point. Choose Base for a smaller download; consider Medium, Large v3 or Turbo for difficult speech if your computer has enough memory. Speed varies with your computer and recording.
DownloadApproximate file sizeWhat to consider
Base148 MBSmaller download and faster processing for clear recordings
Small488 MBBalanced speed and accuracy
Medium1.53 GBMore memory; can help with difficult recordings
Large v33.10 GBHighest download size and memory use among these choices
Turbo · Compressed575 MBCompact version of a larger model; speed depends on your computer
All these download choices support multiple languages. An installed model labeled English only is for English recordings. Existing compatible models can include Tiny or other English-only variants. Their actual file sizes appear in the chooser and may differ from the download table because their file format differs. The size is disk space for the model file, not the amount of memory needed while it runs. Whisper models and the speaker-label tools are downloaded separately from the FlowJoe installer. Choosing a large model does not make everyone else’s installer larger.

Make a transcript

  1. Choose a node or slot in Joe’s target bar, then select the recording in Source. The visible Source heading also names this selector for assistive technology. A node shows recordings grouped by slot, including the audio items in each stack. Choosing a recording targets its slot. A slot target shows only recordings in that slot; selecting the node again returns to all its slots.
  2. Choose your Transcription method.
  3. For local transcription, choose an installed Local model. Under Options, choose Plain text, Whisper - Timestamps or Speaker Labels + Timestamps. For online transcription, the original Model menu offers the paid choices.
  4. Leave Language on Auto, or choose English when appropriate.
  5. Click Transcribe. The button changes to Stop, with a working indicator. The status shows the current stage and elapsed time; a percentage appears only when the engine supplies one. Click Stop to cancel. While stopping, wait for the recording to be released. Your previous transcript and edits return after cancellation.
  6. Review or edit the result. Copy copies the text. Save opens the destination chooser so you can put the transcript in gallery notes or a summary. The history marks it saved only after the destination is saved successfully.
Changing Options affects your next transcription. It does not rewrite text already in the transcript box. Online transcription saves a result only after the service confirms it is complete. If the connection ends early or stops sending data for 90 seconds, the run fails rather than saving a partial transcript as finished. You can retry the recording. Stop also works while the online result is arriving.

Return to a transcript

Completed transcripts and your edits are kept automatically for the current Flow, even before you save a gallery copy. Returning to Transcribe after a reload restores the latest transcript. Open Recent transcripts to reopen an earlier result, remove one, or clear the history. Removing history does not delete the recording or a copy you saved in the gallery. Clear removes the transcripts currently available in the list, including available results marked Keep on this computer only. It does not remove records inside locked Private nodes. Unlock the node first to remove those results.
Retained transcripts and edits of a Private node are saved encrypted under the same node password, including older transcripts saved before you made the node Private. Saved text, older versions and normal Recent access stay available after unlocking. This does not change the choice between local and paid-online transcription.
The transcription method controls where speech recognition runs. Storage follows the Flow’s storage mode:
  • Local mode, including a standalone browser: transcript history is kept in this browser or app’s local data, separately for each Flow. Clearing browser/app data removes that local copy; use an export for a backup.
  • Workspace folder: eligible history is also kept in the Workspace’s .flowjoe/transcript-history.json file and restored when that Workspace opens. Private-source transcripts and transcripts marked Keep on this computer only stay in local data instead.
Transcript history is registered app data and is excluded from orphaned-media cleanup. Private transcripts become unavailable when their source is locked. A transcript whose source was removed remains available in history for copying or saving, subject to its privacy restrictions. In owner chat and authorized external CLI/MCP sessions, you can ask Joe to find or quote a retained transcript in the current Flow. He reads bounded text portions with source dates only when the recording still has an admitted public source. Private, Hidden from Joe, removed and uncertain sources stay unavailable to this reader, even if you can still copy them in the human history. A recording converted into a stack or moved to another public node keeps its retained source link. Ambiguous or newly private sources are withheld. Reading does not upload the audio or start recognition. Joe reads a bounded portion of history already loaded with the Flow; unusually large or unavailable retained collections can be unavailable to this reader while ordinary History remains readable. Results may be partial; guests and scheduled runs do not receive these readers. Authorized external CLI/MCP sessions can use them with Read or Propose access; see the action reference. Joe can also read a Private node’s own transcripts after you unlock their still-available recording source. Hidden from Joe and locked or uncertain sources remain unavailable. Exports have an Include transcript history option, enabled by default. Private-source transcripts start excluded; explicitly include their Private nodes to include eligible transcripts. An already-unlocked node does not require its password again. Computer-only transcripts remain excluded. See Export & Import. If FlowJoe can’t read the saved transcript history, the Flow still exports without it and a notice says so; the kept transcripts on your computer are left unchanged. If you open a Flow whose transcript history was saved by a newer FlowJoe, this version still shows it, but new transcripts and edits are not kept there; FlowJoe warns you and the text stays copyable. In a Workspace folder saved by a newer FlowJoe, new transcripts stay on this computer.

Shared guests

Open Recent transcripts in Transcribe to read the retained results shared with you. Private sources and transcripts the owner keeps on their computer are excluded. Removing a recording does not remove its retained text when its shared origin is known. Selecting a recording still restores its retained text after the owner merges it into a stack or reopens the Flow. Hiding the recording or moving it outside your share also withholds its retained words, even when other pictures in the same stack remain shared.
  • View access: open and read shared retained results. When the owner enables Joe, transcribe shared audio into a personal result and edit it in your browser. This personal draft survives closing Joe or reloading the same browser tab; it does not change the owner’s history. Saving into shared content requires Edit access.
  • Edit access: edit retained text and save a gallery copy through the existing Save chooser. Text edits are saved through the owner, with a pending recovery copy in your browser.
  • Removal: Edit can remove its own results; removing someone else’s results or a separate conflict result they contributed requires the owner’s elevated removal permission. A mixed removal tells you what was kept. Ordinary text edits do not change who created the result.
The owner keeps the authoritative history with the Flow. Ending or losing access to the share clears the guest browser’s shared data and pending drafts; it does not delete the owner’s history. Keep on this computer only is controlled by the owner. Reading existing results does not require permission to run Joe; new online recognition uses the owner’s enabled connection. Personal drafts are cleared when their audio is hidden or removed, the guest’s role changes, or the share ends. Local model setup remains a desktop function.

Plain text, timestamps and speaker labels

  • Plain text: readable recognized text without added time markers.
  • Whisper - Timestamps: each segment includes a start time such as [01:24].
  • Speaker Labels + Timestamps: separates voices into numbered speakers, with a time marker on each line. Local setup downloads the speaker detector alongside Whisper, with no account or token needed. The same speaker tools work with all Whisper models and stay installed across ordinary FlowJoe updates. After setup, both transcription and speaker labels work offline. Speaker numbers distinguish voices; they do not identify people.
Local plain text and timestamps use the same recognition model. Choose the model for speed and accuracy, and choose Options for how the transcript should look. All local model sizes have no per-use API fee.

Change, add or remove a model

Use Manage local models any time. Selecting a model to inspect it does not change your saved method/model; click Use to adopt it. Under More options, Locate an existing model… lets you select a compatible model file that FlowJoe did not find automatically. FlowJoe checks the file before offering it. An unrelated or modified model file may be refused. A model downloaded by FlowJoe can be removed from this screen after confirmation to free disk space. FlowJoe does not delete model files it found elsewhere on your computer. If a selected model is removed or moved, choose another ready model or download it again. A FlowJoe update may offer a tested new speaker engine; local setup downloads that version when needed and removes the old engine after successful installation. Unchanged engines are reused. New model choices may arrive with FlowJoe updates. You choose whether to download a bigger or different model; FlowJoe does not replace your selected model automatically. Transcripts keep following their original recording when you merge audio into a stack. Moving that stack into a Private node excludes its retained transcripts from exports by default. The owner can explicitly include eligible transcripts by selecting the Private node; an already-unlocked node does not require its password again, and unlocking alone does not include it. An Edit guest with export permission can include eligible retained transcripts; FlowJoe checks access again before saving the export.

Ask Joe about a YouTube video

Paste a YouTube link (or ask about a video you have open) and Joe can read what is said in it. If FlowJoe’s built-in browser was closed, it rises to just its tab row at the bottom of the window. A YouTube tab with a small Joe badge appears beside your own active tab; Joe’s status line says Reading the video’s captions…. A video Joe opens stays paused and muted the whole time. You can keep working while Joe reads. When Joe is done, his tab closes and the browser goes back to how it was: if it was closed, it slides away again; if you had tabs open, you stay on yours. If you expanded the browser meanwhile, it stays open. If the video is already open in one of your own tabs, Joe reads it there and leaves your tab as it is.

​
Try it with an example

Open Joe chat, give Joe at least Read-only Flow access, and paste:
Read the captions of https://www.youtube.com/watch?v=UF8uR6Z6KLc. Summarize Steve Jobs’ three stories, give a timestamp for each, and explain his main takeaway.
You should briefly see Joe’s badged tab beside your own tab in the browser’s bottom tab row. It closes when the read finishes, and Joe answers in the chat with a summary and timestamps. If you already have that video open, Joe uses your tab and leaves it open without pausing or muting it. No local transcription model is needed for YouTube captions. Then, in the same conversation, try:
Using that transcript, explain the connecting-the-dots section and give its timestamp.
Joe reuses the transcript already read for that conversation, so this follow-up does not need to open the video again.

​
What to expect

  • The whole transcript, however long. Joe reads the full captions — a three-hour podcast included — and works through a long transcript in sections, quoting with timestamps.
  • Captions are needed. Joe reads YouTube’s own transcript. If a video has none, Joe says so; you can send him the transcript another way, or transcribe a recording you have.
  • YouTube asks for a person. If YouTube shows its unusual-traffic check, Joe stops and tells you right away. Open YouTube in FlowJoe’s browser to complete the check yourself, then ask Joe again. Joe does not try to pass the check or retry it.
  • Stopping. Stop in the Joe chat, or closing Joe’s tab yourself, ends the read. Stop also cancels a request waiting behind another read without waiting for that video to finish.
  • Your YouTube account. Joe’s tab uses the same YouTube session as your built-in browser, so videos Joe reads can appear in your YouTube watch history and recommendations.
  • History and saved tabs. Joe’s tab is never added to your browser history or saved tabs, and it can’t be brought back with Reopen Closed Tab.
  • Guests. A guest’s Joe can read a YouTube video too, when the owner has Joe switched on for that guest. The read happens on the owner’s computer: the owner briefly sees Joe’s tab in their tab row. If the owner switches off a guest’s Joe while a request is waiting, that request will not open a tab.
  • Every brain. This works the same whichever brain runs Joe. Outside assistants connected through the Agent Bridge can’t use it.

Privacy, limits and troubleshooting

Local transcription keeps the audio on your computer and works offline after setup. If you later attach or paste the transcript into an online Joe conversation, that text follows the chat provider’s normal processing rules. Local transcription has no length or file-size limit — a long meeting or lecture runs in one go, and takes as long as your computer needs. FlowJoe first converts the recording in a separate, locked-down background step (so even a damaged or malicious audio file never reaches Whisper directly), which needs free memory for a very long recording; if your computer runs out, FlowJoe tells you so — the app itself keeps running — and you can close other apps or split the file. The recording must be in an audio format your computer can decode. Your audio output device’s sample rate does not affect local transcription. Quitting FlowJoe stops pending model detection as well as active transcription.
  • No compatible model found: choose a download, or use More options to locate a supported file.
  • Download did not finish: check your connection and available disk space, then retry. Your saved method/model stays unchanged.
  • Model unavailable: it may have moved or been removed. Open management and choose a ready model.
  • Local engine unavailable: use a supported desktop build with the transcription engine included. Compatible existing models may still be available. FlowJoe will not automatically upload your recording.
  • Slow transcription: try a smaller model or close other memory-heavy apps. Free transcription uses this computer’s resources.
  • Wrong words: try a clearer recording or a more capable model, and review the transcript before relying on it.
Online transcription accepts recordings up to 25 MB. Use a shorter or compressed recording if yours exceeds that limit. For online transcription, the app shows the selected model and its published cost estimate. OpenAI bills API usage separately from any ChatGPT subscription. See Token usage with Joe for other paid AI activity.

Remove a downloaded model

Open Manage local models, choose a model downloaded by FlowJoe, and expand More options. Choose Remove downloaded model, then confirm in FlowJoe’s dialog. Cancel or Escape keeps it. You can download it again later. Models found outside FlowJoe remain untouched, and removing a model does not remove your recordings or saved transcripts.

Add finished transcripts beside their recordings

After a background Chat transcription finishes, Joe offers Add to gallery or Not now using his usual proposal card. You can keep chatting while deciding. Nothing is added before you accept. Add to gallery saves each complete transcript as a text document in a stack with its matching audio, on the same node. The audio stays first. Joe confirms where he put the documents; Show in gallery selects the matching transcript. The confirmation remains available in conversation history. Not now leaves the results in Recent transcripts, with their opening lines and separate Open buttons. Opening one does not replace or remove another. Keep on this computer only controls the retained result; accepting Add to gallery creates a separate gallery copy that follows the node’s sharing rules. If the gallery changes appear but saving fails, Joe says they are still unsaved. The confirmation keeps Show in gallery; the same proposal cannot add another copy. Use FlowJoe’s normal Save or Undo to recover. The opening transcript preview, Open, and Copy remain available after adding it to a stack.

​
Transcribe part of a recording

Ask Joe, “Transcribe only the first minute of this podcast,” or specify a start and end time. FlowJoe prepares that excerpt before speech recognition or an online upload; it does not transcribe the full recording and cut the text afterward. The recording stays unchanged. The background card shows the requested interval, and the retained result keeps its time range. Transcript timestamps are relative to the excerpt. If you correct a running job to a shorter interval, Joe can stop that job and start the requested excerpt after stopping finishes. Each new reply receives the current job state so Joe can check what is actually running.

​
Existing models after an update

Your local model selection and installed model files stay on this computer across builds. FlowJoe also recognizes existing compatible Whisper models. On macOS, an existing Homebrew Whisper installation can use the matching installed library recorded by its PyTorch installation when Homebrew’s current library link has changed. This recovery is limited to the Whisper process. It does not download another model. If the engine cannot start, Joe reports an engine problem and directs you to repair Whisper or choose another installed model. That is distinct from a missing-model setup request. FlowJoe does not silently switch to paid transcription.

​
Background progress

The background transcription card lines up with the chat prompt field. It shows a percentage when the engine supplies one, and names preparation or speaker detection when those steps are running. A recognition percentage does not measure the later speaker-detection step. Joe’s status clears that percentage when the next step starts. A remaining-time estimate appears only after enough measured local recognition progress. Near completion, during speaker detection, or when timing is unavailable, the card says it is still estimating instead of promising a finish time.
